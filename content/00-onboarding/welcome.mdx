# 🎓 Bienvenido a CyberEdu Zero-Trust Academy

## Introducción

Has dado el primer paso para convertirte en un experto en ciberseguridad. Esta plataforma está diseñada bajo el principio **Zero-Trust**: nada es confiable por defecto, todo debe ser verificado.

> 💡 **Concepto Clave**: Zero-Trust significa que nunca asumimos que algo es seguro solo porque está "dentro" de nuestra red. Cada acceso debe ser autenticado y autorizado.

## Arquitectura de la Plataforma

Nuestra plataforma opera 100% en el navegador:

```
┌─────────────────────────────────────────────────┐
│                 Tu Navegador                    │
│  ┌─────────┬──────────────┬─────────────────┐  │
│  │ Sidebar │   Contenido  │    Terminal     │  │
│  │  (JSON) │    (MDX)     │     (WASM)      │  │
│  └─────────┴──────────────┴─────────────────┘  │
│         IndexedDB + localStorage + SW           │
└─────────────────────────────────────────────────┘
```

### Componentes Principales

1. **Sidebar (Izquierdo)**: Navegación JSON-driven con progreso persistente
2. **Panel Central**: Contenido educativo renderizado desde MDX
3. **Terminal (Derecho/Inferior)**: Xterm.js conectado a módulos WASM

> 🚨 **Advertencia de Seguridad**: Todo el procesamiento ocurre localmente. Tus datos NUNCA salen del navegador.

## Tu Primer Desafío

Antes de comenzar, necesitamos verificar que tu terminal está funcionando correctamente.

### Paso 1: Abre la Terminal

Presiona `Ctrl + Shift + T` o haz clic en el panel derecho para enfocar la terminal.

### Paso 2: Ejecuta el Comando de Verificación

```bash
$ cyber-edu --verify
```

Deberías ver una salida similar a:

```
✓ Sistema verificado
✓ Módulos WASM cargados
✓ Entorno listo para aprendizaje
```

> 🛠️ **Problemas Comunes**: Si la terminal no responde, verifica que JavaScript esté habilitado en tu navegador.
